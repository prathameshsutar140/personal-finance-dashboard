
# FlowVault - Transaction & Account Manager

FlowVault is a clean, responsive single-page web dashboard designed to manage personal finance, track multi-account balances, log transaction histories, and visualize cash flow dynamics[span_1](start_span)[span_1](end_span).

## Features

* **Multi-Account Management:** Create and track multiple accounts (Checking, Savings, Credit Card, Investment, Cash Wallet) with real-time net worth calculation[span_2](start_span)[span_2](end_span).
* **Transaction Logging:** Record income, expense, and transfer transactions with automated balance adjustments across source and destination accounts[span_3](start_span)[span_3](end_span).
* **Financial Analytics:** Interactive visual charts powered by Chart.js showcasing monthly cash flow breakdowns and category-wise expense distributions[span_4](start_span)[span_4](end_span).
* **Search & Filtering:** Search through transaction records by description, linked accounts, or transaction type[span_5](start_span)[span_5](end_span).
* **Data Backup & Restore:** Export your state to a JSON backup file and import existing financial records seamlessly[span_6](start_span)[span_6](end_span).

## Tech Stack

* **Frontend:** Standard HTML5 and modern JavaScript (ES6+)[span_7](start_span)[span_7](end_span)
* **Styling:** Tailwind CSS (via CDN)[span_8](start_span)[span_8](end_span)
* **Icons:** Lucide Icons[span_9](start_span)[span_9](end_span)
* **Charts:** Chart.js[span_10](start_span)[span_10](end_span)

## Quick Start

1. Clone or download the repository[span_11](start_span)[span_11](end_span).
2. Open `app.html` directly in any modern web browser—no local server setup or `npm install` required[span_12](start_span)[span_12](end_span).
