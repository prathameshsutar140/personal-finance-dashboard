
# FlowVault - Transaction & Account Manager

FlowVault is a clean, responsive single-page web dashboard designed to manage personal finance, track multi-account balances, log transaction histories, and visualize cash flow dynamics.

## Features

* **Multi-Account Management:** Create and track multiple accounts (Checking, Savings, Credit Card, Investment, Cash Wallet) with real-time net worth calculation.
* **Transaction Logging:** Record income, expense, and transfer transactions with automated balance adjustments across source and destination accounts.
* **Financial Analytics:** Interactive visual charts powered by Chart.js showcasing monthly cash flow breakdowns and category-wise expense distributions.
* **Search & Filtering:** Search through transaction records by description, linked accounts, or transaction type.
* **Data Backup & Restore:** Export your state to a JSON backup file and import existing financial records seamlessly.

## Tech Stack

* **Frontend:** Standard HTML5 and modern JavaScript.
* **Styling:** Tailwind CSS (via CDN)
* **Icons:** Lucide Icons
* **Charts:** Chart.js.

## Quick Start

1. Clone or download the repository.
2. Open `app.html` directly in any modern web browser—no local server setup or `npm install` required.
